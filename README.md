# Эвотор — ЛК клиента: прототип пути по воронке

Кликабельный HTML-прототип личного кабинета, в который клиент попадает по ссылке от менеджера после звонка. Показывает путь от заполнения данных до решения по заявке на финансирование.

Прототип — один статичный файл `index.html` без сборки и зависимостей. Данные в нём вымышленные, на сервер ничего не отправляется.

## Шаги

1. **Данные компании** — телефон из заявки (только чтение), ИНН с поиском организации, согласия.
2. **Паспорт** — главная страница и страница с регистрацией, ошибка распознавания и повторная загрузка.
3. **Условия** — сумма и срок, выставленные менеджером; клиент только подтверждает.
4. **Выписки** — загрузка выгрузок из 1С по каждому счёту, проверка формата, покрытие периода. Отправка ссылки бухгалтеру для загрузки выписок.
5. **Подписание** — пакет документов и код из SMS.
6. **Решение** — ожидание, выдача или отказ.

Отдельный экран — **страница бухгалтера**, которую он открывает по ссылке из шага 4.

## Как пользоваться прототипом

Тёмная панель сверху — служебная, её нет в продукте:

- **Экран** — переключение между клиентом и бухгалтером по ссылке.
- **Шаг 1–5 / Итог** — переход к любому шагу; предыдущие шаги заполняются сами.
- **Решение** — какой исход покажет экран ожидания: одобрение или отказ.
- **Начать заново** — сброс состояния.

Тестовые сценарии:

| Где | Что сделать | Что увидите |
|---|---|---|
| Шаг 1 | Ввести ИНН `0000000000` | Организация не найдена |
| Шаг 1 | Ввести любой ИНН из 10 или 12 цифр | Найдена ИП Смирнова А. В. |
| Шаг 2 | Загрузить главную страницу | Первая попытка — ошибка распознавания, вторая — успех |
| Шаг 4 | Нажать на зону загрузки | Три файла: два принимаются, `.docx` — ошибка формата; удалите его, чтобы продолжить |
| Шаг 4 | «Отправить ссылку» | Форма отправки бухгалтеру по SMS или email |
| Шаг 5 | Ввести код `0000` | Неверный код; любой другой код подписывает документы |

## Запуск локально

Откройте `index.html` в браузере. Для копирования ссылки в буфер обмена нужен `https` или `localhost`, например:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Публикация на GitHub Pages

1. Settings → Pages.
2. Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту прототип будет доступен по адресу `https://<аккаунт>.github.io/<репозиторий>/`.

Учтите: на бесплатном тарифе GitHub Pages для приватного репозитория недоступен, а сайт из публичного репозитория видят все, у кого есть ссылка.
